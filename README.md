# Композиция

Небольшой редактор для сборки иллюстраций из готовых SVG-объектов. Он не рисует новые элементы: загруженные векторы остаются отдельными слоями в итоговом файле.

Рабочая версия: https://musyase.github.io/svg-composition-studio/

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки и экспорта:

```bash
npm test
npm run build
```

## Как пользоваться

1. Загрузить несколько исходных SVG в левую панель. Названия и метки объектов можно поправить прямо в списке.
2. Выбрать сценарий: идея/заголовок или список конкретных объектов. Ввести запрос и выбрать расположение. Сборка ищет совпадения по названиям и меткам; если их нет, просит уточнить запрос. Состав можно изменить вручную.
3. Перетаскивать объекты на холсте. Во вкладке «Слои» доступны порядок, видимость, поворот, ширина, копирование и удаление.
4. Выбрать цветовую схему либо загрузить JSON, CSS или TXT с цветами `#RRGGBB`. Первый цвет загруженного файла станет фоном, остальные — цветами объектов. Палитра меняет заливки и обводки, не геометрию.
5. Скачать SVG. Его можно открыть в Figma или другом редакторе и выбрать каждый объект отдельно.

Проект сохраняется в IndexedDB браузера. Сервис работает локально, без сервера и загрузки иллюстраций куда-либо.

## Устройство

- При импорте SVG очищается от исполняемых и внешних ресурсов. `viewBox`, пути, группы, градиенты и пропорции сохраняются.
- Одна запись библиотеки может использоваться на холсте несколько раз. При сборке SVG идентификаторы внутри каждой копии получают свой префикс, поэтому ссылки на градиенты и маски не конфликтуют.
- На холсте каждый объект представлен отдельной группой с координатами и поворотом. Экспорт создаёт XML с теми же группами, а не снимок экрана.
- Автоматический подбор намеренно прозрачен: словарь близких понятий и совпадения с названиями/метками. Внешний AI API и ключи для запуска не нужны. Если подбор неудачен, объект можно добавить вручную.
- Исходные иллюстрации компании не входят в репозиторий. Их нужно загрузить через интерфейс после получения разрешённого экспорта из Figma.
